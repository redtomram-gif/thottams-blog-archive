Topics: CLR internals, assembly loading and versioning, reflection and Reflection.Emit, NTSD/SOS debugging, COM interop, generics, and System.Data.

Where a post has an accompanying runnable sample, the code lives in its own repository and is linked below rather than duplicated here.
