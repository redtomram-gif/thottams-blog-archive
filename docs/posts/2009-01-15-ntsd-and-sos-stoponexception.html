NTSD and SOS: StopOnException

2009-01-15 original post code sample →

!StopOnException comes in handy when you want to break when a specific exception occurs.

The program below throws an OutOfMemoryException on every iteration of the loop except one, where it throws a single ArgumentException. That gives you something to practise on: plenty of noise, and one exception you actually care about.

Build it with debug information and start it under the debugger:

Add the current directory to the symbol path, break when the runtime is loaded, and let the program go:

Now that mscorwks is loaded, load SOS, tell it to stop the first time an ArgumentException is created, and continue:

The debugger breaks on the iteration that throws ArgumentException. !ClrStack -a shows the managed stack along with the parameters and locals of each frame:

The first local of ExceptionSample is 0x3c, which is 60 — exactly the iteration that throws the ArgumentException.

!pe prints the details of the exception itself:

This will stop when the exception occurs. You can print the details of the exception using !pe and look into the locals using !ClrStack -a. This comes in handy when you want to debug a problem and break at the point the exception is thrown, rather than sifting through every exception the process happens to raise.
